## Architecture principles

- Security and ownership checks belong on the server
- Prices, payments, and fulfilment events require server-side verification
- Public data access should be minimal and protected by RLS
- Webhooks and order creation must be idempotent
- Interfaces should be responsive, accessible, and resilient to loading and error states
- Production systems need monitoring, retries, logs, and a safe deployment path
