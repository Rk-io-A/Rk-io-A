## Development Approach

When I build or review a .NET application, I focus on:

1. **Maintainability** — clear project structure and separation of responsibilities
2. **Security** — protected secrets, safe authentication, authorization, and least privilege
3. **Data integrity** — reliable database design, validation, and migrations
4. **Reliability** — useful error handling, logging, and failure-aware integrations
5. **Performance** — efficient queries, async I/O, caching where appropriate, and scalable APIs
6. **Deployment** — repeatable configuration, CI/CD, monitoring, and cloud readiness
