## How I build

- Start with clear product requirements and domain boundaries
- Keep sensitive credentials on trusted server infrastructure
- Treat client-provided prices and authorization claims as untrusted
- Design integrations behind provider-neutral interfaces
- Use migrations, RLS, idempotency, and automated checks from the beginning
- Prefer small, understandable modules over unnecessary complexity
- Document deployment, recovery, and operational limitations
